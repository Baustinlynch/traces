## Common lines of code you should know

- `pinMode(pin#, INPUT or OUTPUT);` — initializes the pin as a way to give or receive information.
- `delay(#milliseconds);` — pauses the loop for the defined number of milliseconds.
- `if (__==__){_______}` — an if statement, allowing conditions to affect what is run.
- `analogWrite(pin#, value)` / `digitalWrite(pin#, value)` — defines the pin as high or low, or (for analog) a value between 0 and 255 for voltage application.
