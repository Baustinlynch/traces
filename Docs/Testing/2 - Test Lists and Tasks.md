# Lists and Task Lists

## Unordered list

- apples
- bananas
  - yellow
  - ripe
- cherries

## Ordered list

1. first
2. second
3. third

## Nested mix

1. top level
   - nested bullet
   - another bullet
2. second top level

## Task list

- [x] Read the guide
- [ ] Build the circuit
- [ ] Ship the project
- [x] Get the grant

## Inline usage inside a sentence

You can also write flows like: `- [ ]` and `- [x]` directly in a paragraph to see what happens.
